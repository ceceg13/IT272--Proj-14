PROJECT 14-2 - UPDATE THE INDEXED STUDENT MASTER FILE

Purpose
-------
Reads CRSEREG sequentially, reads STUMASTI randomly by student ID, updates
completed units and total grade points, and writes missing student
transactions to ERRRPT.

Required repository layout
--------------------------
PROJECT14_2_CODESPACES.cobc
uploads/crsereg.dat
myfiles/stumasti.dat

The indexed STUMASTI must first be created by Project 14-1. Keep any index
companion files generated by GnuCOBOL in the myfiles directory.

Compile
-------
cobc -x -free -o project142 PROJECT14_2_CODESPACES.cobc

Run
---
./project142

Output
------
myfiles/stumasti.dat  - updated indexed student master
myfiles/errrpt.txt    - missing student transaction report

Important
---------
Running this program more than once applies the course units and grade points
again. To restore the original indexed master, rerun Project 14-1 before
rerunning this program.

If CRSEREG has a different filename, change the CRSEREG ASSIGN path in the
source so it exactly matches the uploaded file.
